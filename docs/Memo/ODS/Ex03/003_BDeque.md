# BDeque: Block固定のDeque  
これは簡単なのですぐ終わらせる.  
固定サイズのDequeである.  
`Add,Remove,Get,Set`を同じく備えているが、メモリの確保はしない.  
ではどこでするのかというと、最初に固定値を決めてしまうのである.  

```c++
BDeque(int b)
    : m_data(b + 1)
    , m_start(0)
    , m_size(0)
{
}
```

サイズ`b`で固定したらこれ以上は確保しない.  
固定値の配列にDeque操作が付いたものともいえる.  
この後の実装では特にDequeのサイズを変えずに行うので,このようなものを実装した次第である.
