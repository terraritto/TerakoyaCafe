# 黒体への道 その2: キルヒホッフの法則(放射)  
前回のシュテファン＝ボルツマンの続き.  
熱が高くなるとエネルギーも高くなるというのが得られたんだった.  

ではそもそもなんで熱について調べるようになったかというと、歴史的に考えると産業革命の影響が大きい.  
産業革命により、鉄を精錬する溶鉱炉が出現する.  
この鉄をしっかりと作るためには安定した温度が必要で、そのためには温度を測る必要がある.  

産業革命なので鉄だけど、個人的にはこれを陶器に言い換えた方がしっくりくる.  
陶器を作るためには温度によって色々と変わってくる.[^1]  
食器なら900~1000度あたりを主とする粘土で問題ない.  
しかし、鍋とかの料理に使うような調理器具を作る際は,1200~1350度くらいとなるらしい.  
大事よね、やっぱりこういうところは.  

また陶芸家なんかは実際に作品を作るために適した素材だけでなく、その素材を何度で焼けばよいかなんかを何度も試行し再現を行う.  
温度が分からなければ再現を行うためには感覚に頼る必要があるので、相当困難なこととなる...  

さて、ちょっと話がそれたが要は「より速く、より正確な温度を知りたい」のである.  
これが分かるとありがたいわけである.  

ここで黒体という物体を考える.  
黒体というのは理想的(仮想的ともいえるのか？)な物体で、すべての光を吸収するような物体.  
普通光が物体に当たると、透過/反射/吸収がそれぞれ少なからず起こるはず.  
しかし、黒体は吸収しかおこらない、そんな物体である.  

CGで考えるならレイトレが分かりやすい.  
ボリュームレンダリングとかサブサーフェースを計算しない限り基本吸収を扱うことはないが、もしこれを扱い実際に吸収のみを行う物体を置いたとする.  
そうするとRayは物体に吸い込まれるので、カメラにRayが届くことは決してない.  
つまり黒色になるわけだ,光がカメラに届かなきゃそこは黒になるからね...  
そういう意味で考えると個人的には黒体は分かりやすいかなぁと思う.レイトレを知ってる前提だけども.  
さて、そしたらここで「キルヒホッフの法則」[^2][^3]を考えよう.  
高校の電磁気で習うあの法則とは全く別のものである.  
これは単純なもので、「温度と波長が同じであれば、輻射率$`E`$と吸収率$`\alpha`$の比は同じ」ということになる.  
ある物体が$`E,\alpha`$,もう一つの物体が$`E^{\prime}, \alpha^{\prime}`$とすると、

```math
\frac{E}{\alpha} = \frac{E^{\prime}}{\alpha^{\prime}}
```

となるわけだ.  
省略しているが、温度と波長に依存しているので$`E(\lambda,T),\alpha(\lambda,T)`$なわけなのには注意.  

Wiki[^4]やここのノート[^5]なんかはキルヒホッフの法則を「放射率と吸収率が等しい」となっているが、行ってることは同じだと思う.  

```math
\frac{E}{E^{\prime}} = \frac{\alpha}{\alpha^{\prime}}
```

と変換すれば、ちゃんと放射率と吸収率になってるしね.  

因みに余談なのでスルーしてもらってもいいが、Wikiに面白いことが書いてあったので紹介する.[^6]  
まず、放射率を$`\epsilon`$,吸収率を$`a`$とすると、キルヒホッフの法則より,

```math
\epsilon = a
```

ここで反射率を$`\rho`$,透過率を$`\tau`$とすると、エネルギー保存則より,  

```math
\rho + \tau + a = 1
```

物体が厚い場合を考えよう.この場合透過はほぼ$`\tau=0`$と考えられるので、これとキルヒホッフの法則を当てはめると反射率は

```math
\rho = 1 - \epsilon
```

こうして反射率の関係が求まった.  
ここにおいて大事なのは放射率が小さいと反射率が大きくなるという点である.  
これを応用できるのが消防服.  
消防服は表面が金属でコーティングされているが、これは放射率が小さいからである.  
こうすることで反射率が高くなり、熱放射を跳ね返すことで消防員の体を守れるという寸法.合理的だ...  
キルヒホッフの法則のすごさがちょっとわかるのではないでしょうか？  

さて、黒体に話を戻そう.  
キルヒホッフの法則において$`E^{\prime}`$側が黒体であったとすると、$`\alpha^{\prime}=1`$なので、

```math
\frac{E}{\alpha} = E^{\prime}
```

というのが言える.  
これがキルヒホッフの法則に黒体を当てはめたときの面白い性質.  
$`E^{\prime}(\lambda,T)`$となっていることから、黒体の放射するエネルギーは温度と波長のみで決まる！！！！  
もう一つ、どんな物体でも放射率と吸収率の比を取れば黒体の放射率になるというのもあるが、これよりは先程の方が今回は重要である.  

黒体の放射するエネルギーは温度と波長のみで決まるというのは分かった.  
だが、そもそも黒体なんてものが存在するの...？というのが次の問い.  

実はこれに近い状態が炉の中で起きており、これが「空洞放射」[^2][^7]というものになる.  
炉に小さな穴をあけた場合、そこから光が入ってくる.  
入った光は何度も反射する中で壁に吸収され、ついには全部吸収されてしまうことになる...  
これは黒体と同じことが起こってることになる、黒体は吸収率が1だったね.  
そして、壁の温度に応じた電磁波が逆にこの穴からは出てくる.これが空洞放射だ.  

ここまでくれば実際に放射エネルギー$`E`$がどんな形をしてるのかが知りたくなってくる頃だ.  
温度から求まるステファン=ボルツマンの法則は放射発散度,つまり全スペクトル域を合計したエネルギーとなるわけである.  
$`E`$はある波長に対する関数であるので,つまりステファン=ボルツマンの法則とは一致しないわけである.  

ではこれをどう予測したのか、次回はこれを見ていくことにして今回は終わりにしておく.
