# シェルソート  
シェルソート[^1]はコムソート[^2]のように間隔を決定して、それを元に挿入ソート[^3]を行うソート.  
今回も例に漏れず例を見てみよう.  
```
8 3 1 2 7 5 6 4 n=8

1回目 h=n/(2*1)=4
8 3 1 2 7 5 6 4
A B C D A B C D  間隔4でクラス分け

A 8 7 で8の方がでかいので入れ替え
7 3 1 2 8 5 6 4

B 3 5 で5の方がでかいので入れ替え無し

C 1 6 で6の方がでかいので入れ替え無し

D 2 4 で4の方がでかいので入れ替え無し

よって
7 3 1 2 8 5 6 4

2回目 h= n/(2*2)=2
7 3 1 2 8 5 6 4 間隔2でクラス分け
A B A B A B A B

A 「7 1 8 6」を挿入ソートすると、「1 6 7 8」なので、
1 3 6 2 7 5 8 4

B 「3 2 5 4」を挿入ソートすると、「2 3 4 5」なので、
1 2 6 3 7 4 8 5

3回目 h = n/(2*3)=1
7 3 1 2 8 5 6 4 間隔1でクラス分け
A A A A A A A A

A 「7 3 1 2 8 5 6 4」を挿入ソートすると、「1 2 3 4 5 6 7 8」なので、
1 2 3 4 5 6 7 8 完了！
```
こんな感じで間隔毎に計算してる、コムソートに近いでしょ？  
さて、そうなると間隔をどう選ぶかが大事になってくる.  
これは色々提案があるが、今回でも取り上げられていた2で割っていく方式で今回は実装する.  
この方式がドナルド・シェルが最初に提案した間隔となる.  

つまり,

```math
h_{k} = \lfloor \frac{n}{2^{k}} \rfloor
```

ということになる.  
あとはこれをコードに落とし込めばよい.  
まずは`gap`に毎回計算した間隔を入れて、1を切れないように調整したものを`h`とする
```c++
    int gap = dataList.size();
    int h = 0;
    do
    {
        gap /= 2;
        h = Max(gap, 1);
```
あとは各間隔`h`を使って比較し、もしダメなら挿入ソートを行う.  
挿入ソートの際は`h`に沿ってソートをするようにすればよい.  
```c++
        for (int i = h; i < dataList.size(); i++)
        {
            if (dataList[i].weight < dataList[i - h].weight)
            {
                int j = i;
                auto tmp = dataList[i].weight;

                do
                {
                    dataList[j].weight = dataList[j - h].weight;
                    j -= h;
                } while (h <= j && dataList[j - h].weight > tmp);
                dataList[j].weight = tmp;
            }
        }
        result.push_back(dataList);
    } while (1 < h);
```
こうして得られた結果を見てみよう、今回も中間あたり.  

うん、段上に綺麗にソートされていってる！  
ちゃんと動作してるっぽいね.
